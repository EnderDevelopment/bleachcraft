# Bleachcraft

Bleachcraft is a Minecraft mod that brings the world of Bleach into the game. This mod features Shikai and Bankai transformations, unique abilities for each character, and epic boss fights. It includes a variety of characters from the Bleach series, each with their own distinct abilities and transformations.

## Install

1. Download the latest version of the mod from the [releases page](https://github.com/yourusername/bleach_mod/releases).
2. Place the downloaded JAR file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Launch Minecraft with the mod installed.
2. To transform into Shikai, use the designated item or command.
3. To transform into Bankai, use the designated item or command.
4. Engage in battles with the included bosses and other characters.
